## Учебный проект Course_prodject_1
# *Приложение для анализа денежных транзакций*

Это проект приложения, в котором разработаны функции для анализа транзакций, находящихся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставлять другие сервисы.

**В данном проекте реализованны три задачи по одной из каждой из трёх категорий.**

#### Задачи по категориям:
*Веб-страницы:*
- [ ] Главная
- [x] События

*Сервисы:*
- [ ] Выгодные категории повышенного кешбэка
- [x] Инвесткопилка
- [ ] Простой поиск
- [ ] Поиск по телефонным номерам
- [ ] Поиск переводов физическим лицам

*Отчеты:*
- [ ] Траты по категории
- [x] Траты по дням недели
- [ ] Траты в рабочий/выходной день

Основные функции реализованы в отдельных модулях: 
1. views.py
2. services.py
3. reports.py

Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек 
user_settings.json

*Пример:*

`{"user_currencies": ["USD", "EUR", "CNY"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]}`

Для получения данных о валютах и ценах на акции используется библиотека
`requests`

*Сервисы, предоставляющие API для курса валют и цен на акции:*

- <https://apilayer.com>
- <https://site.financialmodelingprep.com>

### Структура проекта
+ src/main.py — модуль, запустив который, можно получить результат всех реализованных в проекте функциональностей.
+ src/views.py — модуль, предоставляет JSON-ответ содержащий следующие данные о расходах, переводах, наличных, поступлениях,
курсе валют и курс акции 5-и публичных компаний S&P500.
+ src/services.py — модуль, который определяет какую сумму удалось бы отложить в 'Инвесткопилку'
+ src/reports.py — модуль, который возвращает средние траты в каждый из дней недели за последние три месяца (от переданной даты)
+ data/user_settings.json — это файл файле пользовательских настроек в формате .JSON (JavaScript Object Notation)
+ data/operations.xlsx — это файл содержащий список банковских операций в формате .XLSX (формат файла для электронных таблиц Microsoft Excel)
+ src/utils.py — модуль, в котором расположены все вспомогательные функции
+ logs/ — пакет для файлов логирования
+ tests/ — пакет с модулями для проверки работоспособности и отладки ПО
+ .env_template — файл для конфигурации с базами данных

### Установка
Чтобы работать с проекта необходимо:
1. Загрузить проект в IDE через инструмент *'clone repository'* или команду `git clon`
   используя ключь: 
    - SSH: `git@github.com:L-Ev-Vi/Course_project_1.git`
    - или HTTPS: `https://github.com/L-Ev-Vi/Course_project_1.git`;
2. Установить зависимости проекта, выполнив команду `poetry install`;
3. В некоторых случаях может не корректно устанавливаться пакет `dateutil`, в этом случае можно установить пакет в ручную:
    - через `Terminal` используя команду `poetry add --group dev python-dateutil`
    - или через `pip install python-dateutil`

### Тестирование
Проверка работоспособность программы проводится в пакете `tests`, структуру которой составляют:
- модуль `conftest.py` для хранения фикстур;
-  и тестируемые модуль `test_utils.py`

В модуле задаются параметры для функций, и проводится отработка сценариев поведения программы.
- Для проведения тестов используется фреймворк `pytest`, он устанавливается вместе с зависимостями проекта, но также 
возможно выполнить установку через команду: `poetry add --group dev pytest`
- Запуск тестов производится через команду `pytest` (или конфигурацию используемой IDE)

Для формирования отчёта о том какое количество кода охвачено тестами в процентном соотношении, устанавливается библиотека 
'pytest-cov' через команду: `poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:
+ `pytest --cov` — при активированном виртуальном окружении.
+ `poetry run pytest --cov` — через poetry.
+ `pytest --cov-report term-missing --cov=src` — проверка покрытия тестом с выводом строк
+ `pytest --cov=src --cov-report=html` — чтобы сгенерировать отчет о покрытии в HTML-формате
  - при последнем варианте был сгенерирован отчет `index.html` который храниться в папке `htmlcov`.

### Запуск проекта
1. В модуле main.py запустите функции `events, savings, spending_by_day_the_week`
используя один из предложенных сценариев с заданными параметрами или задайте свои:
```commandline
if __name__ == "__main__":
    print(events("2021-05-18 23:55:13"))
    print(savings("2021-08", 100))
    print(spending_by_weekday("2021-02-18"))
    
    
    print(events("2019-10-05 23:55:13"))
    print(savings("2021-08", 1000))
    print(spending_by_weekday())
    
    
    print(events("2020-02-18 23:55:13"))
    print(savings("2021-08", 50))
    print(spending_by_weekday("2018-04-30"))
```
    - на Windows через *Terminal:* `python src\main.py`
    - на iOS через *a-Shell:* `python3 src/main.py`
    - на Linux через *Linux Terminal:* `python3 src/main.py`
